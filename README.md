# Gestión de Reclamos – Barrio Privado

Trabajo práctico de la materia **Proceso de Desarrollo de Software** (UADE) · **Grupo 1**

Sistema de escritorio en Java para gestionar los reclamos de un barrio privado. Los vecinos
cargan reclamos sobre los espacios comunes, el intendente los asigna al personal del área
que corresponde (seguridad, mantenimiento, jardinería o administración) y los empleados
actualizan su estado hasta resolverlos. Cada cambio queda registrado en un historial.
